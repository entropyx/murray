# Architecture

The Murray project is structured as a Python package with a Streamlit user interface.

## Main Components

- **`app.py`:** This is the main entry point for the Streamlit application. It handles user authentication and navigation.
- **`dashboard.py`:** This file contains the code for the admin dashboard, which displays application usage metrics.
- **`experimental_design.py`:** This Streamlit page guides users through the process of designing a new geo-based experiment.
- **`experimental_evaluation.py`:** This Streamlit page allows users to evaluate the results of a completed experiment.
- **`Murray/` (directory):** This is the core Python package containing the logic for the geo-incrementality analysis.
    - **`main.py`:** Contains the main functions for running the analysis, including `BetterGroups` for finding optimal treatment/control groups and `evaluate_sensitivity` for power analysis.
    - **`auxiliary.py`:** Provides helper functions for data cleaning and preparation, such as `handle_duplicates` and `market_correlations`.
    - **`metrics.py`:** Handles the logging of application usage metrics.
    - **`plots.py`:** Contains functions for generating plots and visualizations for the Streamlit app.
- **`utils_auth.py`:** Manages user authentication, including creating and validating users.

## Data Flow

1.  **User Uploads Data:** The user uploads a CSV file with their marketing data through the Streamlit interface (`experimental_design.py`).
2.  **Data Cleaning:** The data is cleaned and processed by functions in `Murray/auxiliary.py`.
3.  **Group Selection:** The `BetterGroups` function in `Murray/main.py` is used to find the optimal treatment and control groups.
4.  **Power Analysis:** The `evaluate_sensitivity` function in `Murray/main.py` runs simulations to determine the Minimum Detectable Effect (MDE).
5.  **Results Display:** The results are displayed to the user in the Streamlit interface, with plots generated by `Murray/plots.py`.
