# Project Summary

This project, named **Murray**, is a Python package and Streamlit application for geographical incrementality testing. It helps users determine the true lift of marketing campaigns through advanced synthetic control methods.

## Key Features

- **Geographical Incrementality Testing:** The core functionality of the project is to analyze the impact of marketing campaigns in specific geographical locations.
- **Synthetic Control Methods:** It uses synthetic control methods to create a counterfactual model of what would have happened without the marketing campaign.
- **Minimum Detectable Effect (MDE) Analysis:** The application can generate heatmaps of MDEs across different configurations to help users optimize their treatment selection.
- **Impact Analysis:** It provides impact analysis through counterfactual modeling.
- **Streamlit Application:** The project includes a Streamlit application with two main sections:
    - **Experimental Design:** To help users design their experiments.
    - **Experimental Evaluation:** To evaluate the results of their experiments.
- **User Authentication:** The Streamlit application has a user authentication system with different roles (user and admin).
- **Dashboard:** For admin users, there is a dashboard to monitor application usage.
